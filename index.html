The information stored locally on your device is used solely to:

🔑 Permissions Explained

MindFuel requests minimal permissions for notification functionality. Here's a complete list:

POST_NOTIFICATIONS (Android 13+)

  • Purpose: Send you daily motivational quotes at your chosen time
  • Optional: Yes, can be disabled in settings
  • Data Access: None - only displays pre-loaded quotes
  • Note: Required for Android 13+ devices to show notifications

VIBRATE

  • Purpose: Provide haptic feedback for better user experience
  • Optional: Yes, can be disabled in app settings
  • Data Access: None - only device vibration
  • Note: Used for button presses and notification alerts

WAKE_LOCK

  • Purpose: Ensure notifications are delivered even when device is sleeping
  • Optional: Automatic, tied to notification feature
  • Data Access: None - only keeps device awake briefly to show notification
  • Note: Required by Android WorkManager for reliable background scheduling

RECEIVE_BOOT_COMPLETED

  • Purpose: Automatically reschedule notifications after device restart
  • Optional: Automatic, tied to notification feature
  • Data Access: None - only detects device boot to reschedule notifications
  • Note: Ensures your daily quotes continue after phone restarts

FOREGROUND_SERVICE & FOREGROUND_SERVICE_DATA_SYNC

  • Purpose: Enable reliable notification scheduling through Android WorkManager
  • Optional: Automatic, required by Android system for background tasks
  • Data Access: None - only used internally by Android WorkManager
  • Note: These are automatically added by Android's WorkManager library (Google's official background task API). WorkManager is Google's recommended solution for reliable notification scheduling. No foreground services are visible to users.

ACCESS_NETWORK_STATE (Optional, Auto-added)

  • Purpose: May be automatically included by Android libraries
  • Usage: NOT actively used by MindFuel - app works 100% offline
  • Data Access: None - permission exists but is never accessed
  • Note: Sometimes auto-added by AndroidX libraries but remains unused

CHECK_LICENSE (Auto-added by Play Store)

  • Purpose: Google Play Store's built-in license verification and anti-piracy protection
  • Usage: Automatically added by Play Store to verify legitimate app installation
  • Data Access: None by MindFuel - handled entirely by Play Store during installation
  • Network Access: Only used by Play Store at installation time (not by your app)
  • Note: Standard security feature on all Play Store apps. MindFuel's code never accesses this permission. Your app remains 100% offline during use.

DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION (Android Security)

  • Purpose: Android's internal security mechanism to protect broadcast receivers
  • Usage: Automatically created by Android to prevent other apps from sending malicious broadcasts
  • Data Access: None - purely a security boundary
  • User Impact: None - completely invisible to users and developers
  • Note: Standard Android 13+ security feature. Protects your notification system from external interference. No data collection or internet access involved.

Permission Summary:

  • Explicitly Requested by MindFuel: 4 permissions (POST_NOTIFICATIONS, VIBRATE, WAKE_LOCK, RECEIVE_BOOT_COMPLETED)
  • Auto-added by Android/WorkManager: 2 permissions (FOREGROUND_SERVICE, ACCESS_NETWORK_STATE - unused)
  • Auto-added by Play Store: 1 permission (CHECK_LICENSE - for anti-piracy)
  • Auto-added by Android Security: 1 permission (DYNAMIC_RECEIVER - for broadcast protection)

Important: MindFuel remains 100% offline. Auto-added permissions are system-level security features that do not involve data collection or internet access by the app itself. The CHECK_LICENSE permission is only used by Google Play Store during installation to verify legitimate downloads.
